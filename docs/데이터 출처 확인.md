# 데이터 출처 확인

기획서 5.5절 "데이터 출처 (확인 필요)"를 확인한 결과다. 확인일 2026-10-14.

## 1. 레시피: 식품안전나라 조리식품의 레시피 DB (COOKRCP01)

- 안내 페이지: https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=661&show_cnt=10&start_idx=1&svc_no=COOKRCP01

### 제공 필드 (55개)

| 묶음 | 필드 |
| --- | --- |
| 기본 | 일련번호(RCP_SEQ), 메뉴명(RCP_NM), 조리방법(RCP_WAY2), 요리종류(RCP_PAT2) |
| 영양 | 중량 1인분(INFO_WGT), 열량, 탄수화물, 단백질, 지방, 나트륨 |
| 부가 | 해쉬태그(HASH_TAG), 이미지 소/대(ATT_FILE_NO_MAIN / ATT_FILE_NO_MK), 재료정보(RCP_PARTS_DTLS) |
| 조리 순서 | 만드는법 01~20(MANUAL01~20), 단계별 이미지 01~20(MANUAL_IMG01~20) |
| 팁 | 저감 조리법 TIP(RCP_NA_TIP) |

### 요청 변수

- 필수: keyId(인증키), serviceId(`COOKRCP01`), dataType(`json`/`xml`), startIdx, endIdx
- 선택: RCP_NM(메뉴명), RCP_PARTS_DTLS(재료정보), CHNG_DT(변경일자 YYYYMMDD), RCP_PAT2(요리종류)

### 호출 제한

- 한 번에 최대 1,000건
- CHNG_DT 없이 호출하면 시간당 100회, 06~19시에는 키·서비스당 300회
- 파일 다운로드는 키당 서비스별 하루 10회
- 샘플키로는 호출 불가, 인증키 이용신청 필요

### 라이선스

- API 안내 페이지에 **공공누리 유형이 표시되어 있지 않다.** 저작권정책 링크만 있다.
- 공공데이터포털의 다른 식약처 레시피 데이터셋(예: 밥류 정밀화 한식 레시피)은 공공누리 제1유형(출처표시)으로 표시되어 있으나, COOKRCP01에 그대로 적용된다고 볼 수는 없다.
- 결론: 재배포 조건을 확인하기 전에는 레시피 본문과 이미지를 서비스에 싣지 않는다. 인증키 신청 시 이용약관을 확인하고 이 문서에 추가한다.

### 데이터 품질

- 재료정보(RCP_PARTS_DTLS)가 자유 텍스트다. "돼지고기 200g, 양파 1/2개, 대파 약간" 같은 형태라 재료 사전 ID·수량·단위로 바꾸려면 수동 정제가 필요하다.
- 대체 가능 그룹(돼지고기 또는 참치캔)이나 필수/선택 구분이 없다. 플래너가 필요로 하는 구조는 직접 만들어야 한다.
- 조리도구 정보가 없다. 사용자 설정(전자레인지·에어프라이어·오븐)과 연결하려면 직접 태깅해야 한다.
- 결론: 기획서 5.1절의 레시피 DB 구조(필수/선택, 대체 그룹, 사용량, 조리도구)는 API로 채울 수 없다. MVP 100개는 직접 작성한다. 결정 D3 참고.

## 2. 보관 기한

### 국내 공식 자료

- 식약처·식품안전나라는 보관 온도 기준(냉장 0~10℃, 권장 4℃ 이하 / 냉동 -18℃ 이하 / 실온 1~35℃)과 "식품 표시사항의 보관방법을 우선하라"는 원칙을 안내한다.
  - 식품안전나라 "소비기한 도입에 따른 올바른 식품 보관방법(소비자편)": https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?menu_no=2873&bbs_no=bbs109&ntctxt_no=1098866&menu_grp=MENU_NEW05
  - 식품안전나라 식중독 예방 자료에 식품 종류별 냉동 권장기간 일부(익힌 생선 1개월, 해산물 2~3개월, 베이컨·소시지·햄 1~2개월)가 있다.
- 식재료 150종을 냉장/냉동/실온별로 모두 덮는 국내 공식 표는 찾지 못했다.

### 보조 자료: USDA FoodKeeper

- https://catalog.data.gov/dataset/fsis-foodkeeper-data
- 미국 농무부(USDA FSIS)가 공개한 400종 이상의 식품별 냉장·냉동·실온 보관 기간 데이터. JSON·XLS 제공.
- 라이선스: CC0 (퍼블릭 도메인). 재가공·재배포에 제약이 없다.
- 한국 식재료(두부, 김치, 깻잎, 콩나물 등)는 없거나 다르므로 국내 자료와 섞어 쓴다.

### 재료별 출처 기록 방식

- `ingredients.source` 컬럼에 출처 코드를 넣는다.

| 코드 | 의미 |
| --- | --- |
| `mfds` | 식약처·식품안전나라 자료 |
| `usda-foodkeeper` | USDA FoodKeeper |
| `seoul-nutri` | 서울시 식생활종합지원센터 자료 |
| `manual` | 위 자료에 없어 일반 상식과 제조사 표시 기준으로 직접 정한 값 |

- 한 재료에 출처가 여럿이면 가장 보수적인(짧은) 기한을 택하고, 출처는 짧은 기한을 준 쪽을 적는다.
- 화면에는 모든 기한을 "권장"으로 표시하고, 제조사 표시 기한이 있으면 그것을 우선하라는 문구를 재료 추가 시트에 넣는다. (확정)

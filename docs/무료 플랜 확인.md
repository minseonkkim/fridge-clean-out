# 무료 플랜 확인

기획서 6장 "무료 플랜 조건은 자주 바뀌므로 착수할 때 각 요금 페이지에서 다시 확인한다"에 따라 확인한 결과다. 확인일 2026-10-14. 각 서비스 공식 요금 페이지를 기준으로 했다.

## Vercel Hobby

- 요금 페이지: https://vercel.com/pricing
- 가격: $0/월
- 조건: **개인·비상업 용도만** 허용. FAQ에 "Our Hobby plan is for personal, non-commercial use." 명시. 수익화하면 Pro($20/시트/월)로 전환해야 한다.
- 한도를 넘으면 추가 사용량을 살 수 없고 리소스가 멈춘다.

| 항목 | 월 한도 |
| --- | --- |
| Fast Data Transfer | 100 GB |
| CDN 요청 | 100만 건 |
| Fast Origin Transfer | 10 GB |
| 함수 호출 | 100만 회 |
| Fluid Active CPU | 4시간 |
| ISR 읽기 / 쓰기 | 100만 / 20만 |
| Blob 스토리지 | 1 GB |
| 이미지 최적화 변환 | 5,000회 |
| 빌드 머신 | Basic만 |

- 이 서비스에 미치는 영향: 플래너·장보기 추천이 브라우저에서 돌고 Route Handler는 2차 AI 추천에서만 쓰므로 함수 호출 100만 회는 충분하다. 재료 아이콘은 SVG 정적 파일로 두어 이미지 최적화 변환 5,000회를 쓰지 않는다.

## Supabase Free

- 요금 페이지: https://supabase.com/pricing
- 가격: $0/월, 조직당 활성 프로젝트 2개

| 항목 | 한도 |
| --- | --- |
| Postgres 용량 | 프로젝트당 500 MB (Shared CPU, RAM 500 MB) |
| 파일 스토리지 | 1 GB (파일당 50 MB) |
| 월간 활성 사용자(MAU) | 50,000 |
| Egress | 5 GB + Cached Egress 5 GB |

- **비활성 일시정지: 1주일 동안 활동이 없으면 프로젝트가 멈춘다.** 대시보드에서 수동으로 복구해야 한다. 데이터는 유지된다.
- 이 서비스에 미치는 영향:
  - 500 MB는 재료 사전 150종 + 레시피 100개 + 사용자 수천 명의 `fridge_items`·`item_events`에 충분하다. `item_events`가 가장 빨리 커지므로 3단계에서 보존 기간 정책을 정한다.
  - 일시정지를 막기 위해 3단계 베타 전에 GitHub Actions로 하루 한 번 가벼운 쿼리를 보내는 keep-alive를 넣는다. (2차 알림용 GitHub Actions와 같은 워크플로에 둔다.)
  - 레시피 이미지는 Supabase Storage 대신 레포의 정적 파일이나 외부 URL로 두어 1 GB 한도를 아낀다.

## Sentry Developer

- 요금 페이지: https://sentry.io/pricing/
- 가격: $0/월, 사용자 1명, 프로젝트 무제한

| 항목 | 한도 |
| --- | --- |
| 에러 | 5,000건 |
| 로그 | 5 GB |
| 트레이싱 | 5M spans |
| 세션 리플레이 | 50회 |
| 업타임 모니터 / 크론 모니터 | 1개 / 1개 |
| 데이터 보존 | 30일 |

- 한도를 넘으면 그 이상의 이벤트는 버려진다 (과금되지 않음).
- 이 서비스에 미치는 영향: 에러 5,000건이면 베타 규모에서 충분하다. 트레이싱 샘플링 비율을 낮게(0.1 이하) 두고, 세션 리플레이는 끈다. 업타임 모니터 1개를 랜딩에 걸 수 있다.

## 기타

- 도메인: 공개 베타까지 vercel.app 주소. 결정 D5 참고.
- GitHub Actions: 퍼블릭 레포면 무료, 프라이빗 레포는 월 2,000분. keep-alive와 알림 발송 정도면 충분하다.

기준 문서: [냉털 레시피 서비스 기획서](./냉털%20레시피%20서비스%20기획서.md) (2026-10-08)

- 목표: 착수 후 **11주차 공개 베타**
- 가정: 퇴근 후 사이드 프로젝트, 주 10~12시간
- 구성: 5단계 + 단계 사이 완료 기준(◆) 4개. 시간이 더 나면 4단계를 앞당긴다.
- 원칙: 코어 기능을 **목록 화면으로 먼저 완성**해 두고, 냉장고 연출은 그 위에 얹는다. 연출이 늦어져도 서비스는 쓸 수 있어야 한다.
- 주차 배분은 기획서에 없는 항목이라 임의로 나눴다. 진행하면서 조정한다.

진행 상태는 `[ ]` → `[x]`로 바꾼다. 결정 사항은 결정한 내용을 옆에 적는다.

- [ ] 안드로이드·크롬: `beforeinstallprompt` 받아 두고, 재료 3개 이상 등록 또는 두 번째 방문 시 설치 배너
- [ ] 배너 닫으면 7일 동안 다시 띄우지 않음
- [ ] iOS 사파리: "공유 → 홈 화면에 추가" 그림 안내 시트 (같은 조건)
- [ ] 오프라인: 마지막으로 불러온 냉장고·플랜·레시피 읽기 가능
- [ ] 재료 사전·레시피는 받은 뒤 캐시

### 성능 목표

- [ ] 중저가 안드로이드 4G 기준 LCP 2.5초 이하
- [ ] Lighthouse 모바일 성능 90점 이상
- [ ] 재료 1개 등록 소요 시간 중앙값 10초 이하 (직접 측정)

### 품질·안정성

- [ ] Sentry 에러 추적 동작 확인
- [ ] Supabase 무료 프로젝트 일시정지 방지: GitHub Actions로 하루 1회 keep-alive 쿼리
- [ ] 핵심 플로우 E2E 테스트: 가입 → 등록 → 플랜 → 요리 완료 → 장보기
- [ ] 수량 단위 불일치 케이스 점검
- [ ] 유통기한 '권장' 표기와 사용자 수정 가능 여부 최종 확인
- [ ] 개인정보 처리방침·이용약관 (소셜 로그인 심사 대비)
- [ ] 카카오·구글 OAuth 앱 심사·프로덕션 전환

### 지표 측정 준비

- [ ] 재료 소진율 (등록 재료 중 '다 씀' 비율) 집계 쿼리
- [ ] 주간 활성 사용자 비율 집계
- [ ] 플랜 실행률 ('요리 완료' 비율) 집계
- [ ] 등록 소요 시간 측정 이벤트
- [ ] 사용자 피드백 받을 창구 (마이 화면 링크 등)

### 공개 베타

- [ ] 도메인 구입 여부 결정 (vercel.app 유지 vs 구입)
- [ ] 랜딩 페이지 냉장고 데모 마무리
- [ ] 베타 공지·초대 (타깃: 자취하는 20~30대 1인 가구)
- [ ] 베타 피드백 수집 기간 설정

### ◆ 완료 기준 3 · 공개 베타 출시 (11주차)

  - [ ] 소셜 로그인(카카오·구글), 비로그인 체험 → 로그인 시 데이터 이전

  - [ ] 레시피 100개, 다일 식단 플랜, 요리 완료 시 자동 차감
  - [ ] 최소 장보기 추천과 장보기 목록

- [ ] 성능 목표(LCP, Lighthouse)를 넘겼다

## 4단계 · 2차 기능 (베타 이후, 시간이 나면 앞당김)

베타 피드백과 지표를 보고 순서를 정한다. 가장 큰 리스크가 '등록 피로'이므로 F1-3과 F6을 우선 검토한다.

### F1-3 영수증·사진 등록

- [ ] 영수증 OCR 또는 장바구니 사진에서 재료 목록 추출
- [ ] 추출 결과 확인·수정 후 일괄 등록

### F6 알림

- [ ] Web Push(VAPID) 구독
- [ ] GitHub Actions 예약 실행으로 매일 아침 "오늘 먹어야 할 재료" 발송
- [ ] 기한 D-1 알림
- [ ] 마이 화면 알림 설정 (`notify_time`)
- [ ] iOS는 설치된 웹앱에서만 푸시 가능하므로 알림 켜기 버튼을 설치 안내와 연결

### F4-2 AI 맞춤 추천

- [ ] 무료 할당량이 있는 LLM API 선택
- [ ] Next.js Route Handler 한 곳에서만 LLM 호출 (API 키 보호)
- [ ] 입력: 재료 목록, 남은 일수, 설정, 규칙 플랜 결과 / 출력: JSON(날짜별 요리·사용 재료·추가 구매·조리법)
- [ ] 응답 재료명을 재료 사전과 대조해 지어낸 재료 걸러내기
- [ ] 취향·알레르기·조리도구 반영
- [ ] 사용자당 하루 호출 제한, 결과 캐시

### F5-2 냉장고 공유

- [ ] `fridge_members` 테이블 활성화 (role: owner/editor)
- [ ] 가족·룸메이트 초대 링크
- [ ] RLS 정책을 공유 멤버까지 확장
- [ ] 마이 화면 냉장고 공유 설정

### 오프라인 쓰기 동기화

- [ ] 오프라인 수정(수량 변경 등)을 기기에 쌓아 두기
- [ ] 온라인 복귀 시 동기화, 충돌 처리 규칙

### 플래너 고도화

- [ ] 빔 서치(폭 20) 또는 정수계획법으로 버려지는 재료 수 최소화 (재료 30개·7일 기준)
- [ ] 그리디 결과와 비교해 개선 여부 확인

### ◆ 완료 기준 4 · 2차 기능 안정화

- [ ] 선택한 2차 기능이 베타 사용자에게 열려 있다
- [ ] AI 호출 비용이 무료 할당 안에 머문다
- [ ] 푸시 알림이 안드로이드·iOS(설치된 웹앱) 모두에서 도착한다

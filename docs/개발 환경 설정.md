# 개발 환경 설정

로컬에서 앱을 돌리고 배포하기까지 사용자가 직접 해야 하는 계정 작업을 모았다. 코드 쪽 준비는 끝나 있으므로 여기 적힌 값만 채우면 된다.

## 1. 로컬 실행

```bash
npm install
cp .env.example .env.local   # 값은 아래 2번에서 채운다
npm run dev
```

환경 변수가 비어 있어도 앱은 뜬다. 이때는 비로그인 체험 모드(브라우저 저장소)만 동작한다.

## 2. Supabase 프로젝트 만들기

1. https://supabase.com/dashboard 에서 새 프로젝트를 만든다. 리전은 Northeast Asia (Seoul)을 고른다.
2. Project Settings > API에서 아래 두 값을 복사해 `.env.local`에 넣는다.
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - Publishable key (`sb_publishable_...`) → `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
     (구형 프로젝트라면 anon key를 `NEXT_PUBLIC_SUPABASE_ANON_KEY`에 넣어도 된다.)
3. 서비스 롤 키(secret)는 쓰지 않는다. 권한은 RLS로만 제어한다.
4. 테이블·RLS·트리거·RPC는 `supabase/migrations/`에 있다. 둘 중 한 방법으로 적용한다.
   - **SQL Editor**: 대시보드 SQL Editor에서 파일 이름 순서대로 붙여 넣고 실행한다.
   - **Supabase CLI**: `npx supabase login` → `npx supabase link --project-ref <프로젝트 ref>` → `npx supabase db push`
5. 로컬 검증은 Supabase 없이 `npm run test`로 한다. PGlite(WASM Postgres)에 마이그레이션을 모두 적용하고 RLS·트리거·RPC를 사용자 권한으로 시험한다 (`supabase/tests/`).

### 로그인 제공자 (1단계 F5에서 켠다)

- Authentication > Providers에서 Kakao, Google을 켠다.
- 각 제공자 콘솔(카카오 디벨로퍼스, Google Cloud Console)에 Supabase가 알려 주는 Redirect URL을 등록한다.
- 로컬 테스트용으로 Authentication > URL Configuration의 Site URL에 `http://localhost:3000`, Redirect URLs에 `http://localhost:3000/**`를 추가한다.

## 3. Vercel 배포

1. https://vercel.com/new 에서 GitHub 레포 `minseonkkim/fridge-clean-out`을 가져온다. 프레임워크는 Next.js로 자동 감지된다.
2. Environment Variables에 `.env.local`과 같은 값을 넣는다 (Production, Preview 모두).
3. 배포가 끝나면 `*.vercel.app` 주소가 생긴다. 그 주소를 Supabase의 Site URL / Redirect URLs에도 추가한다.
4. 이후 main 브랜치에 푸시하면 자동 배포된다.

## 4. Sentry

1. https://sentry.io 에서 Next.js 프로젝트를 만든다 (Developer 무료 플랜).
2. DSN을 `.env.local`과 Vercel 환경 변수의 `NEXT_PUBLIC_SENTRY_DSN`에 넣는다.
3. 비워 두면 Sentry는 초기화되지 않는다.

## 5. 코드 구조 (Supabase 관련)

| 파일 | 역할 |
| --- | --- |
| `src/lib/supabase/env.ts` | 환경 변수 읽기, 없으면 명확한 에러 |
| `src/lib/supabase/client.ts` | 브라우저용 클라이언트 (싱글턴). 대부분의 데이터 접근 |
| `src/lib/supabase/server.ts` | 서버 컴포넌트·Route Handler용 클라이언트 (요청마다 생성) |
| `src/lib/supabase/proxy.ts` | 요청마다 세션 쿠키 갱신 |
| `src/proxy.ts` | Next.js 16 Proxy 진입점 (구 middleware). 정적 파일은 제외 |
